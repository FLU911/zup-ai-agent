# Установка

Проверено на: платформа **8.3.27.1859**, Vanessa Automation **1.2.043.28**,
1С:ЗУП КОРП 3.1, Windows 11.

## Что должно быть

| Компонент | Откуда |
|---|---|
| Vanessa Automation | https://github.com/Pr-Mex/vanessa-automation/releases |
| Расширение MCP-сервера для менеджера тестирования | https://github.com/1c-neurofish/onec-client-mcp-devkit/releases |
| Расширение `VAExtension` для клиента тестирования | поставляется с Vanessa Automation |
| Внешняя компонента `VanessaExt` | включается в настройках Vanessa Automation |
| Claude Code (или Cline / Continue / Roo Code / OpenCode) | ваш выбор |

## Шаги

1. **Развернуть базу 1С:ЗУП** и рабочую копию для агента.
   Агент выполняет реальные действия в базе — на проде не запускайте.

2. **Поставить расширение MCP-сервера** из
   [onec-client-mcp-devkit](https://github.com/1c-neurofish/onec-client-mcp-devkit/releases)
   в базу **менеджера тестирования**.

3. **Запустить Vanessa Automation в режиме менеджера тестирования.**
   Можно из командной строки, чтобы MCP-сервер поднялся сразу:

   ```batch
   "<каталог платформы>\8.3.27.1859\bin\1cv8c.exe" ENTERPRISE /TESTMANAGER ^
     /IBConnectionString "File=""<путь к вашей базе>"";" ^
     /Execute "C:\vanessa-automation\vanessa-automation.epf" ^
     /C "runMcp;mcpPort=8080"
   ```

   Порт `8080` — тот, что прописан в `.mcp.json` этого проекта.
   Если поставите другой — поправьте `.mcp.json`.

4. **Включить внешнюю компоненту `VanessaExt`** в настройках Vanessa Automation.

5. **Поставить расширение `VAExtension`** в базу клиента тестирования.

6. **Завести профиль клиента тестирования** с именем ровно `AGENT_TEST_CLIENT`.
   В Vanessa Automation: таблица клиентов тестирования → добавить.
   Имя профиля жёстко зашито в скиллы и в `CLAUDE.md`.

   | Поле | Значение |
   |---|---|
   | Имя | `AGENT_TEST_CLIENT` |
   | Строка подключения | ваша база, например `File="<путь к вашей базе>";` |
   | Дополнительные параметры | `/N"Агент"` — отдельный пользователь 1С для агента |
   | Тип клиента | Тонкий |

   Отдельный пользователь 1С важен: по журналу регистрации всегда видно,
   что сделал агент, а что — человек.

7. **Склонировать этот проект и открыть его в Claude Code.**

   ```bash
   git clone <url> zup-ai-agent
   cd zup-ai-agent
   claude
   ```

   `.mcp.json` в корне проекта Claude Code подхватит сам и спросит разрешение
   на подключение MCP-сервера. Проверить: команда `/mcp` — сервер `VA`
   должен быть `connected`.

## Проверка

Попросите агента:

```
Проверь окружение
```

Ожидаемо: агент вызовет `get_environment_data` и вернёт версию платформы,
версию Vanessa Automation, строку соединения с базой менеджера тестирования.

Дальше:

```
Подключи клиент тестирования
```

Ожидаемо: поднимется сеанс 1С под пользователем `Агент`,
`connect_test_client` вернёт «Статус: подключен».

## Другие IDE

В каталоге `configs/` лежат готовые конфиги для Cline, Continue, Roo Code
и OpenCode. Скопируйте нужный по адресу, который ждёт ваш плагин:

| Среда | Путь |
|---|---|
| Claude Code | `.mcp.json` в корне проекта |
| Continue | `%USERPROFILE%\.continue\mcpServers\VanessaAutomation.yaml` |
| Cline | `%APPDATA%\Code\User\globalStorage\saoudrizwan.claude-dev\settings\cline_mcp_settings.json` |
| Roo Code | `%APPDATA%\Code\User\globalStorage\rooveterinaryinc.roo-cline\settings\mcp_settings.json` |
| OpenCode | `%USERPROFILE%\.config\opencode\opencode.jsonc` или `opencode.jsonc` в корне проекта |
