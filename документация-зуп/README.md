# Документация по 1С:ЗУП

Папка намеренно пустая. Сюда кладётся методическая документация по
конфигурации — например, книга «Зарплата и управление персоналом» с ИТС.
Это материалы фирмы «1С»: копировать их в репозиторий и выкладывать
в открытый доступ нельзя.

## Зачем она нужна агенту

Чтобы объяснять человеку **бизнес-смысл** операции, а не только порядок
нажатий: почему при увольнении компенсация считается так, откуда берётся
база по взносам, что попадает в 6-НДФЛ. Ссылаться на такие материалы
агент должен номером главы и раздела, а не цитатой.

## Как заполнить

Сложить сюда свои файлы (md, pdf, html) по главам. Удобно — по одному
файлу на главу, с номером в начале имени:

```
05_учет-кадров.md
15_расчет-зарплаты-и-взносов.md
18_ндфл-и-отчетность-в-фнс.md
```

## Правило для агента

Читать — можно, и только когда нужно объяснить человеку логику операции.
Копировать отсюда в другие файлы репозитория, в отчёты и в письма —
нельзя. Во время выполнения операции сюда не ходить: сначала довести
операцию до конца.

Содержимое папки закрыто в `.gitignore` — всё, кроме этого файла.
