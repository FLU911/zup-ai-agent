# Сканы документов для демо

Генератор синтетических «сканов», из которых агент извлекает реквизиты и
заводит физлицо и сотрудника в ЗУП.

```
python generate_scans.py --count 20
```

В `комплекты/` сейчас 20 человек. Генератор идемпотентен: при том же
`--seed` комплект с номером N всегда получается одинаковым, поэтому
увеличение `--count` дописывает новых людей и не трогает старых —
эталон уже сгенерированных не меняется.

**Сколько людей может быть.** Имена берутся из списка `PEOPLE` по кругу
(`PEOPLE[i % len(PEOPLE)]`). Если попросить больше комплектов, чем людей
в списке, ФИО начнут повторяться — с другими ИНН и паспортами, но с теми
же фамилией и датой рождения. Нужно больше — дописывать `PEOPLE`,
и только В КОНЕЦ: вставка в середину сдвинет индексы и переснимет
эталоны у всех, кто идёт следом.

```
комплекты/04_Дорохов_Сергей_Владимирович/
    паспорт.png     разворот страниц 2-3, вертикальный
    инн.png         свидетельство, форма № 2-1-Учет
    снилс.png       страховое свидетельство ОПС, зелёная карточка
эталон/
    04_Дорохов_Сергей_Владимирович.json
```

Вёрстка снята с настоящих бланков — образцы лежат в `образцы бланков (в репозиторий не входят)`.
В этом и смысл демо: агент читает реальную структуру документа, а не
подпись под картинкой.

## Что в каждом документе

**Паспорт.** Разворот вертикальный: страница 2 сверху, страница 3 снизу,
между ними красная перфорационная полоса — именно так выглядит скан.
Гильош, подложка `RUSSIA`, круглая печать подразделения, две подписи,
рамка фотографии, машиночитаемая зона внизу. Серия и номер — **перфорацией**,
точками, по правому краю, дважды.

**Свидетельство ИНН.** «Форма № 2-1-Учет», «Код по КНД 1122022»,
орнаментальная рамка, ИНН в разрядку, подпись заместителя начальника
инспекции, фиолетовая печать, голограмма и серия бланка внизу справа.

**СНИЛС.** Зелёная карточка «Страховое свидетельство обязательного
пенсионного страхования». Обратите внимание: **даты в ней прописью** —
`27 ИЮНЯ 1978`, `8 марта 1999 года`. Агенту приходится приводить их к
`27.06.1978`, и это хорошая проверка на понимание, а не на распознавание.

## Документы намеренно нерабочие

Подлинность выключена сознательно, и снимать это нельзя:

| Что | Как сделано | Зачем |
|---|---|---|
| Серия паспорта | `99 XX` | такие серии не выдаются |
| Регион ИНН | `99` | такого кода региона нет |
| Серия бланка ИНН | `99 № …` | вне диапазона |
| Эмитенты | «ТЕСТОВЫМ ОВД ДЕМОНСТРАЦИОННОГО ОКРУГА», «ТЕСТОВАЯ ИФНС РОССИИ № 9900» | не существуют |
| Печати | по центру написано «ОБРАЗЕЦ» | видно на любом кадре |
| Каждый лист | водяной знак «ОБРАЗЕЦ» + красная строка «НЕ ЯВЛЯЕТСЯ ДОКУМЕНТОМ» | видно со сцены |

Государственную символику не рисуем: на месте герба — абстрактная розетка.

**А контрольные разряды — настоящие.** ИНН считается по двум весовым
свёрткам, СНИЛС — по сумме с весами 9…1 по модулю 101. Иначе 1С не примет
значения: проверка встроена прямо в поле ввода. Это тот случай, когда
«сделать заведомо неправильные данные» было бы проще, но демо бы не поехало.

## Два потока случайных чисел

Данные и отрисовка используют **разные** генераторы:

```python
data_rnd = random.Random(seed)              # реквизиты человека
rnd = random.Random(seed * 7919 + i)        # бумага, шум, наклон, печати
```

Иначе правка одной линии в отрисовке сдвигает последовательность, и у всех
людей меняются ИНН и номера паспортов — вместе с эталоном и примерами в
документации. Проверено на себе дважды.

## Эталон — только для проверки

`эталон/*.json` содержит то, что генератор нарисовал на картинке.
**Агенту его давать нельзя** — иначе демо превращается в чтение JSON.
Файл нужен, чтобы после прогона сверить, что модель прочитала скан верно.

Проверено на комплекте 03: 13 полей из 13 совпали с эталоном, включая
перфорированные серию и номер паспорта, СНИЛС и дату регистрации,
записанную прописью.

## Как это встраивается в цепочку

```
сканы  →  агент читает картинки  →  переменные Vanessa
                                          ↓
                       12_СозданиеФизлица.feature     физлицо с ИНН, СНИЛС, паспортом
                                          ↓
                       13_СозданиеСотрудника.feature  сотрудник, связанный с физлицом
                                          ↓
                       01_ПриемНаРаботу.feature       приём на работу
```

Разбор места рождения — работа агента. В паспорте написано
`ПОС. ЛУГОВОЙ ТЮМЕНСКОЙ ОБЛ.`, а форма 1С ждёт отдельно город, район и
область. Агент раскладывает строку по полям сам.
