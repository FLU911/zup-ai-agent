# Правила проекта — в CLAUDE.md

Этот файл нужен инструментам, которые ищут в корне репозитория именно
`AGENTS.md`. Полные правила лежат в [CLAUDE.md](CLAUDE.md) — читай его,
он один для всех агентных оболочек.

Коротко, чтобы не начать работу вслепую:

1. **Агент работает в живой базе 1С:ЗУП руками пользователя** — через
   Vanessa Automation и MCP-сервер, а не через API и не внешней
   обработкой.
2. **Имена форм, полей и кнопок бери только из словаря действий** —
   `СловарьДействий.feature` рядом со скиллом или файл в
   `drafts/словари/`. Нет действия в словаре — значит его нет: скажи
   человеку, а не подбирай похожее имя.
3. **Словари не запускаются.** На каждом стоит `@НеЗапускать`: это
   перечень возможных действий, а не маршрут. Действия выполняет
   модель сама, инструментами MCP.
4. **Feature-файлы не редактируются** без отдельного согласия человека.
   Запрет продублирован тегом `@НеРедактировать` и запретом на запись
   в настройках.
5. **Успех подтверждается базой, а не ответом инструмента.** «Кнопка
   успешно нажата» — это про нажатие; проведение подтверждают
   `get_table_data` и закрывшееся окно документа.

Где что лежит:

| Что | Где |
|---|---|
| правила и границы | `CLAUDE.md` |
| порядок операций | `.claude/skills/*/SKILL.md` |
| словари действий | рядом со скиллом и в `drafts/словари/` |
| как читать базу, известные проблемы | `docs/` |
| настройки MCP для разных оболочек | `configs/` |
| различия Claude Code и OpenCode | `docs/10-claude-и-opencode.md` |

Проект живой и меняется по ходу подготовки доклада — см. раздел
«Работа идёт» в [README.md](README.md).
