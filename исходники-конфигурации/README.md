# Исходники конфигурации 1С:ЗУП

Папка намеренно пустая. Исходники конфигурации «Зарплата и управление
персоналом» принадлежат фирме «1С», выкладывать их в открытый репозиторий
нельзя — поэтому здесь лежит только это описание.

## Зачем она нужна агенту

Выгрузка конфигурации в XML — самый честный способ ответить на вопросы,
на которые интерфейс отвечает плохо:

* какая функциональная опция включает нужный документ
  (`FunctionalOptions/<Имя>.xml`, блок `<Content>`);
* как на самом деле называется реквизит или табличная часть;
* какие бывают виды документов и как они связаны между собой.

## Как заполнить

Конфигуратор → «Конфигурация» → «Выгрузить конфигурацию в файлы…» →
выбрать эту папку. Дальше агент читает её обычными файловыми
инструментами, поиском по имени объекта.

Структура после выгрузки:

```
Catalogs/            справочники
Documents/           документы
FunctionalOptions/   функциональные опции
InformationRegisters/ регистры сведений
Reports/             отчёты
...
```

Содержимое папки закрыто в `.gitignore` — всё, кроме этого файла.
