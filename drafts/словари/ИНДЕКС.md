# Указатель словарей: какой файл открыть под какую задачу

Словарь — это проверенные вызовом имена элементов формы, порядок шагов
и ловушки конкретного участка ЗУП. **Открывай нужный файл ДО первого
действия в 1С**: один `read` дешевле трёх промахов по именам и намного
дешевле разбора формы через `get_form_analysis(format='elements')`.

Все пути — от корня проекта, папка `drafts/словари/`. Всего словарей
в папке больше полутора сотен — ниже только те, что нужны чаще всего;
остальные ищи по имени документа: `drafts/словари/<ИмяДокумента>.feature`.

| Задача | Файл |
|---|---|
| **Любой ввод в табличную часть и любое проведение документа** | `ОбщиеПриемыФорм.feature` |
| Сколько сотрудников работает на дату, кто именно, состав организации | `СоставСотрудниковНаДату.feature` |
| Приём на работу, позиция штатного расписания, ставки | `ПриемНаРаботу.feature` |
| Увольнение, расчёт при увольнении, СТД-Р, 2-НДФЛ уволенному | `Увольнение.feature` |
| Материальная помощь, в том числе при рождении ребёнка | `МатериальнаяПомощь.feature` |
| Приз, подарок сотруднику, доход в натуральной форме | `ПризПодарок.feature` |
| Начисление зарплаты и взносов, закрытие месяца | скилла `zup-month-close` + `ВедомостьНаВыплатуЗарплаты.feature` |
| Ведомости на выплату: банк, касса, перечислением | `ВедомостьНаВыплатуЗарплаты.feature` |
| 6-НДФЛ, ЕФС-1, контрольные соотношения, выгрузка | `КвартальнаяОтчетность6НДФЛиЕФС1.feature` |
| Проверка отчётности, КС, выгрузка в файл | `ПроверкаОтчетностиКСиВыгрузка.feature` |
| Электронная почта в 1С: чтение писем, ответ, вложения | `ЭлектроннаяПочтаПисьма.feature` |

Файла под твою задачу нет — работай по общим правилам системного
промпта и **заведи новый словарь по итогам**, чтобы следующий раз
был дешевле.

## Три вещи, которые экономят больше всего

1. **Факт из базы бери запросом, а не формой.** `get_table_data`
   с `name_filter` отвечает одним вызовом; открытие формы плюс её
   разбор — это пять вызовов и десятки килобайт в контекст.
2. **Ответ инструмента об ошибке содержит список существующих имён.**
   Читай его вместо того, чтобы пробовать следующее имя наугад.
   Три промаха подряд по одной форме означают, что неверен путь,
   а не имя.
3. **Невидимый элемент не оживить.** В дереве элементов у каждого
   стоит `{Видимость:Да|Нет}`. У невидимого поля может показываться
   значение, но любое действие с ним падает. Ищи другой путь к цели.
