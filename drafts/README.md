# Сценарии в работе

Здесь лежат feature-файлы, которые ещё не оформлены в скиллы: они работают,
но пока не приведены к контракту результата (`Попытка / Исключение` +
`РезультатВыполненияАгентомШагаN`), поэтому агент не сможет доложить по ним
внятный итог.

| Файл | Операция | Что надо доделать |
|---|---|---|
| `ЕФС1.feature` | ЕФС-1 (ОСС): заполнение, сохранение, проверка выгрузки | обернуть этапы, перевести переменные в общий нейминг, оформить скилл |
| `Расчет_отпуска.feature` | расчёт и проведение неоплаченных отпусков пачкой | обернуть этапы, добавить итог по количеству обработанных документов, оформить скилл |

Как доводить сценарий до рабочего вида — [docs/03-новый-сценарий.md](../docs/03-новый-сценарий.md).

## Расхождение в именовании

В этих файлах переменные названы `ПеремНаименованиеОрганизации`,
в рабочем скилле 6-НДФЛ — `ПеременнаяНаименованиеОрганизации`.
При оформлении в скилл приводите к варианту `Переменная*`.

## Инструменты

`инструменты/xlsx2tsv.py` — конвертер выгруженных табличных документов
1С в TSV **с сохранением номеров колонок**. Нужен там, где в отчёте
есть пустые ячейки: старый `xlsx2txt.py` их выбрасывает, колонки
съезжают, и разбор по индексу даёт правдоподобный мусор.

```
python инструменты/xlsx2tsv.py отчет.xlsx > отчет.tsv
```

Под Windows запускать с `PYTHONIOENCODING=utf-8`.
