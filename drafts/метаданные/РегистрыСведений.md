# Регистры сведений ЗУП КОРП 3.1 — как их читать и какие нужны

Регистров сведений в конфигурации **больше пятисот**, и подавляющее
большинство — служебные: обмены, версии, кэши, очереди БСП,
`(не используется) …`, `Удалить …`. Полный дамп занимает около
70 000 знаков и не помогает ничем. Поэтому здесь метод и курированный
список, а не перечень.

## Как посмотреть любой регистр сведений

`e1cib/app/Отчет.УниверсальныйОтчет` → Тип объекта = «Регистр сведений»
→ Имя объекта → `СформироватьОтчет` →
`save_table_document_to_file('ОтчетТабличныйДокумент', format='xlsx')`
→ `python инструменты/xlsx2tsv.py`.

Строка заголовка выгрузки — это и есть **список измерений и ресурсов**
регистра. Данных может не быть (в выбранном периоде записей нет),
но состав полей виден всегда.

**Ловушка индексов.** Поля быстрых настроек называются
`КомпоновщикНастроекПользовательскиеНастройкиЭлементN`, и N зависит от
того, ПЕРИОДИЧЕСКИЙ регистр или нет:

| Что выбрано | Элемент0 | Элемент1 | Элемент2 | Элемент3 |
|---|---|---|---|---|
| ничего (свежая форма) | Тип объекта | Имя объекта | Имя таблицы | — |
| непериодический РС | Тип объекта | Имя объекта | — | — |
| периодический РС | Период | Тип объекта | Имя объекта | Имя таблицы |
| регистр накопления | Период | Тип объекта | Имя объекта | Имя таблицы |

То есть индексы съезжают при КАЖДОЙ смене объекта. Не запоминать —
перечитывать форму `get_form_analysis(format="gherkin")` после каждого
шага либо ловить ошибку: она печатает заголовок поля, по которому
сразу видно, куда попал.

Список списка регистров сведений можно вытащить промахом по имени,
но он огромен; проще искать по подстроке через `set_value` с
`exact_match: false`.

## Снятые составы полей (30.08.2026)

### Плановые начисления
Сотрудник · Начисление · Физическое лицо · Документ основание ·
Головная организация · **Используется** · **Действует до** · **Размер**

Периодический. Это то самое место, где живут постоянные надбавки
и доплаты. В базе «Крон-Ц» за 1 квартал 2026 одна запись:
Базин, «Доплата за совмещение должностей», 12 000, действует до 28.02.2026.

### График работы сотрудников
Сотрудник · Головная организация · **График работы** · Действует до ·
(не используется) График работы по окончании

Периодический. Меняется документом «Изменение графика работы списком».

### Бухучет зарплаты сотрудников
Сотрудник · **Способ отражения** · Действует до

Периодический. Задаёт проводку по конкретному человеку; если пусто —
берётся способ подразделения, потом организации.

### Даты выплаты доходов
Оплаченная ведомость · Организация · **Дата оплаты**

**Непериодический** — поля периода на форме отчёта нет вовсе.
Именно отсюда 6-НДФЛ берёт фактическую дату выплаты, когда она
отличается от даты ведомости (документ «Подтверждение выплаты доходов»).

## Соседний слой: регистры накопления по взносам

Для полноты картины рядом с четырьмя регистрами НДФЛ
(см. `РегистрыНакопления.md`) работают взносы:

| Регистр | Что внутри |
|---|---|
| **Учет доходов для исчисления страховых взносов** | база: доход и вид дохода по взносам |
| **Исчисленные страховые взносы** | суммы по каждому тарифу, измерения: головная организация, физическое лицо, организация |
| Страховые взносы по физическим лицам | персонифицированный разрез |
| Расчеты с фондами по страховым взносам | задолженность перед фондами |

Замер по «Крон-Ц» за 1 квартал 2026 (таблица «Обороты»):
единый тариф ПФР **2 947 456,14 ₽**, взносы на страхование от
несчастных случаев **19 447,56 ₽**, 33 записи.
Колонок у регистра много — по одной на исторический тариф
(«ПФР — по суммарному тарифу с 1 января 2014 года» и подобные);
заполнены только актуальные.
