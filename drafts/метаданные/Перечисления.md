# Перечисления ЗУП КОРП 3.1 — те, что реально нужны агенту

Читаются одним вызовом целиком:
`get_table_data(object_type=3, object_name="<Имя>")` — параметр `limit`
для перечислений смысла не имеет.

Инструмент возвращает **и имя значения, и представление**. Заполнять
поля формы нужно ПРЕДСТАВЛЕНИЕМ (то, что видит пользователь),
а сравнивать прочитанное через `get_object_attributes` — по имени.
Это регулярный источник путаницы.

## КатегорииДоходовНДФЛ (32 значения)

Ключевой реквизит: он есть в «Сведениях о доходах» операции учёта
НДФЛ, в ТЧ «НДФЛ» ведомости и в аналитике регистра «Расчеты
налогоплательщиков с бюджетом по НДФЛ». Именно по нему 6-НДФЛ
раскладывает доход по строкам.

| Имя | Представление |
|---|---|
| ОплатаТруда | Оплата труда (основная налоговая база) |
| ПрочиеДоходы | Прочие доходы (основная налоговая база) |
| ПрочиеНатуральныеДоходы | Натуральный доход (основная налоговая база) |
| ДоходВНатуральнойФормеОтТрудовойДеятельности | Неденежные доходы от трудовой деятельности (основная налоговая база) |
| ПрочиеДоходыВДенежнойФормеОтТрудовойДеятельности | Прочие денежные доходы от трудовой деятельности (основная налоговая база) |
| РайонныеСеверныеНадбавки | Районные, северные надбавки |
| Дивиденды | Дивиденды |
| ДивидендыПоСтавке05 / 10 / 12 | Дивиденды по ставке 5 % / 10 % / 12 % |
| ПрочиеДоходыОтДолевогоУчастия | Прочие доходы от долевого участия |
| ПрочиеДоходыПоВыигрышам | Прочие доходы по выигрышам |
| ПрочиеДоходыПоСтрахованиюИПенсОбеспечению | Прочие доходы по страхованию и пенсионному обеспечению |
| ПрочиеДоходыЦБ / РЕПО / ЗаймЦБ / ИИС / ПоОблигациям / ЦФА | операции с ценными бумагами |
| АвторскиеРоялти… по ставкам 3/5/6/7/10/15 % | авторские и роялти |
| ОплатаТрудаАУСН, РайонныеСеверныеНадбавкиАУСН, ПрочиеДоходыАУСН | для АУСН |
| ДовольствиеСВОвДенежнойФорме / вНатуральнойФорме | СВО |
| ПрочиеДоходыПоСтавкеПункта11Статьи224НКРФ | п. 1.1 ст. 224 НК |
| ДоходыПредыдущихРедакций | перенесённые из старых редакций |

**Ловушка.** Четыре похожих «натуральных» и «прочих» категории:
«Натуральный доход», «Неденежные доходы от трудовой деятельности»,
«Прочие денежные доходы от трудовой деятельности», «Прочие доходы».
Подставлять `exact_match: true` обязательно.

## НДФЛСтавкиНалогообложенияРезидента (3)

| Имя | Представление |
|---|---|
| Ставка13 | 13% (для нерезидента 30%) |
| Ставка35 | 35% (для нерезидента 30%) |
| Ставка09 | 13% (до 2015 - 9%, для нерезидента 15%) |

В Разделе 2 отчёта 6-НДФЛ **на каждую ставку своя страница**.
Проверка КС идёт по странице: «Страница 1 Раздела 2» — это 13 %.
Доходы по 35 % (материальная выгода, код 2610) в неё не входят —
не пытаться свести их вместе.

## СтрокиРаздела2Расчета6НДФЛ (4)

Реквизит строки «Сведения о доходах» в операции учёта НДФЛ.
Определяет, в какие строки 110–113 попадёт доход.

| Имя | Представление |
|---|---|
| ТрудовойДоговор | Включать в строки 110 и 112 (по трудовым договорам, контрактам) |
| ДоговорГПХ | Включать в строки 110 и 113 (по договорам ГПХ) |
| Дивиденды | Включать в строки 110 и 111 (дивиденды) |
| НеВключать | Включать только в строку 110 |

## Другие, встречавшиеся в работе

| Перечисление | Где встречается |
|---|---|
| `ХарактерВыплатыЗарплаты` | «Порядок выплаты» межрасчётных документов: «С зарплатой», «В межрасчетный период». **«С зарплатой» ведомостью не выплачивается** — см. открытый вопрос в `ВедомостьНаВыплатуЗарплаты.feature` |
| `ВидыДвиженийНДФЛ` / варианты удержания | «Удержано», «Передано на взыскание в налоговый орган», «Возвращено налоговым агентом», «Зачет авансовых платежей» — реквизит движения регистра «Расчеты налогоплательщиков». «Передано на взыскание» в 6-НДФЛ не попадает вообще |
| `КатегорииДоходовСтраховыхВзносов` | вид дохода по взносам у видов расчёта |

## Как найти нужное перечисление

Промахнуться именем:
`get_table_data(object_type=3, object_name="Нет")` — инструмент
напечатает полный список перечислений конфигурации.
