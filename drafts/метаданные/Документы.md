# Документы ЗУП КОРП 3.1 — полный список имён метаданных

Снят 30.08.2026 приёмом «промах по имени»:
`get_table_data(object_type=2, object_name="ЗаведомоНесуществующее")` —
при неверном имени MCP-инструмент печатает ВЕСЬ перечень документов
конфигурации. Тот же приём работает для справочников (object_type=1)
и перечислений (object_type=3), а для регистров и планов видов
расчёта — через выпадающий список «Имя объекта» Универсального отчёта.

Имена даны так, как их принимает `object_name` и навигационная ссылка
`e1cib/list/Документ.<Имя>` / `e1cib/data/Документ.<Имя>?ref=<hex>`.

**Ловушка имён.** Заголовок в интерфейсе и имя метаданных расходятся:
«Операция учета НДФЛ» — это `ОперацияНалоговогоУчетаПоНДФЛ`
(а не `ОперацияУчетаНДФЛ`), «Операция учета взносов» —
`ОперацияУчетаПоСтраховымВзносам`. Не угадывать: промахнуться и
прочитать список дешевле, чем ловить ошибку позже.
