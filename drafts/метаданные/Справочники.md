# Справочники ЗУП КОРП 3.1 — рабочий каталог

Снят 30.08.2026 приёмом «промах по имени»:
`get_table_data(object_type=1, object_name="ЗаведомоНесуществующийСправочник")`.
Полный список — около 700 имён, но **больше половины из них
`…ПрисоединенныеФайлы`** (по одному служебному справочнику на каждый
документ) плюс десятки платформенных (`КлючиДоступа`, `ВерсииФайлов`,
`ОчередьЗаданий`, `ПолныеПутиКФормам` и т. п.). Здесь оставлено то,
что реально нужно агенту по зарплате и кадрам.

Открывать: `e1cib/list/Справочник.<Имя>`,
читать: `get_table_data(object_type=1, object_name="<Имя>", limit=N)`,
у подчинённых обязателен параметр `owner`.

## Люди

| Имя | Что внутри |
|---|---|
| `ФизическиеЛица` | физлица: ИНН, СНИЛС, паспорт, адрес |
| `Сотрудники` | самостоятельный справочник (НЕ подчинённый), внутри ссылка на физлицо; одно физлицо — несколько сотрудников при совместительстве. Код вида `0000-00036` |
| `Кандидаты`, `ЛичныеДанныеКандидатов` | подбор |
| `РодственникиФизическихЛиц`, `СтепениРодстваФизическихЛиц` | |
| `ОбразованиеФизическихЛиц`, `УчебныеЗаведения`, `УченыеСтепени`, `УченыеЗвания` | |
| `СправкиФизическихЛиц`, `ВидыСправок` | |
| `ГруппыСотрудников` | |

**Важно про пару Физлицо/Сотрудник.** Регистры НДФЛ и взносов ведутся
по **физлицу**, а кадровые документы и ведомости — по **сотруднику**.
Один человек с внутренним совместительством даёт двух сотрудников и
одно физлицо; в 6-НДФЛ он один, в ведомости — две строки. Именно на
этом расходятся расшифровки отчётов и таблицы документов.

## Шум, который можно игнорировать

- `<ИмяДокумента>ПрисоединенныеФайлы` — по одному на каждый документ
  и справочник, ~350 штук. Хранилище вложений, к учёту отношения не
  имеет.
- Платформенные и БСП-шные: `КлючиДоступа`, `ГруппыЗначенийДоступа`,
  `ИдентификаторыОбъектовМетаданных`, `ВерсииФайлов`, `ТомаХраненияФайлов`,
  `ОчередьЗаданий`, `ОбработчикиОчередиЗаданий`, `ПолныеПутиКФормам`,
  `ПоставляемыеДанные`, `СеансыОбменовДанными`, `ЦиклыОбмена`,
  `ХранилищеДвоичныхДанных`, `оидИсторияИзмененияДанных`.
- Подсистемы, не задействованные в этой базе: обучение и развитие
  (`ЭлектронныеКурсы`, `ТестовыеВопросы`, `ЭлектронныеГлоссарии`),
  охрана труда и СИЗ (`СредстваИндивидуальнойЗащиты`, `Размеры`),
  медстрахование (`ПрограммыМедицинскогоСтрахования`), чатботы,
  взаимодействия (`ЭлектронноеПисьмоВходящее`, `ТелефонныйЗвонок`),
  БИА и МЧД.
