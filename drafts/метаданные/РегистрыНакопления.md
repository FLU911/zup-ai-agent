## Четыре регистра НДФЛ — кто за что отвечает

Разобрано 30.08.2026 при починке КС 6-НДФЛ.

- **Учет доходов для исчисления НДФЛ** — доходы, вычеты, исчисленный
  налог. Кормит строки 110–140 Раздела 2.
- **Расчеты налогоплательщиков с бюджетом по НДФЛ** — исчисленный
  (Приход) и удержанный (Расход) по каждому физлицу. Кормит строки
  140, 160, 170, 180.
- **Расчеты налоговых агентов с бюджетом по НДФЛ** — обязательство
  агента по срокам перечисления. Кормит **Раздел 1** (строки 020–026).
  Именно поэтому правка только «налогоплательщиков» ломает КС 1.45.
- **НДФЛ перечисленный / НДФЛ к перечислению** — уплата.
