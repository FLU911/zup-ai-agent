# Отчёты проверки месяца: начислено, НДФЛ, к выплате, выплачено

> `<В УГЛОВЫХ СКОБКАХ>` — подставить из задания. Других значений в этом
> файле нет: всё, что без скобок, — имена отчётов, полей и колонок 1С.

**Что решает:** итоговая таблица после закрытия месяца, свод за месяц
для человека.

Путь проверен вживую 15.09.2026 на отчёте «Анализ зарплаты по сотрудникам
(в целом за период)».

## Путь (одна организация)

    open_list(metadata_path="e1cib/app/Отчет.АнализНачисленийИУдержаний")
        # в разделе «Зарплата → Отчеты по зарплате» панель грузится фоном — ссылка надёжнее
    fill_field(field="Период1ДатаНачала", value="<ПЕРВОЕ ЧИСЛО МЕСЯЦА ДД.ММ.ГГГГ>")
    fill_field(field="Период1ДатаОкончания", value="<ПОСЛЕДНЕЕ ЧИСЛО МЕСЯЦА ДД.ММ.ГГГГ>")
        # по умолчанию стоит период из далёкого прошлого — не пропустить
    select_value(field="Организация", search="<ОРГАНИЗАЦИЯ>")
    click(text="Сформировать")
    wait_seconds(seconds=6)
    get_report(max_rows=5)

Организаций несколько — повторить `select_value` → «Сформировать» → `get_report`
для каждой.

## Как читать

Нужное — в `totals` (строка «Итого»), по подписям колонок:

| В таблице ответа | Колонка отчёта |
|---|---|
| начислено | «Всего начислено» |
| НДФЛ | «НДФЛ» |
| к выплате | «Всего включено в ведомости» (или «Всего начислено» − «Всего удержано») |
| выплачено | «Выплата зарплаты» + «Выплата в межрасчетный период» |
| долг | «Сальдо на конец месяца» (пусто = 0) |

Колонки, которой нет в `totals`, в этой организации в этом месяце не было —
значит 0, а не «не найдено».

## ГЛАВНАЯ ЛОВУШКА: отчёт без отбора врёт колонками

Без отбора по организации отчёт печатает по блоку на организацию, и у
каждого блока своя шапка колонок (у одной есть матпомощь и подарки,
у другой — только оклад). `get_report` берёт ОДНУ шапку на весь отчёт,
и цифры съезжают: 15.09.2026 сумма «Всего начислено» одного филиала
оказалась под подписью «Мат. пом. при рожд. реб.».

**Поэтому — по одному отчёту на организацию, всегда с отбором.**
Проверка: в `meta` стоит «Организация <ОРГАНИЗАЦИЯ>» и только она.

у них разные базы (подарки и прочие доходы входят в базу взносов и НДФЛ,
