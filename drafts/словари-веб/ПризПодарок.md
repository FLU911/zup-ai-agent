# Приз, подарок

> `<В УГЛОВЫХ СКОБКАХ>` — подставить из задания. Других значений в этом
> файле нет: всё, что без скобок, — имена кнопок, полей и кодов 1С.

**Что решает:** оформить подарок или приз сотруднику.

Путь проверен вживую 15.09.2026, 14 вызовов.

    open_list(metadata_path="Документ.ПризПодарок")      # список «Призы, подарки в натуральной форме»
    click(text="Создать")

        # здесь же и вернуться к open_list выше:
        #
        #   open_list(metadata_path="e1cib/app/Обработка.ПанельНастроекЗарплатаКадры.Форма.РасчетЗарплаты")
        #   fill_field(field="ИспользоватьПризыПодарки", value="да")
        #   wait_seconds(seconds=3)       # ОБЯЗАТЕЛЬНО: закрыть сразу — «непредвиденная ошибка»
        #   close_form()                  # кнопки сохранения на этой панели нет, флажок пишется сам

        # «Приз, подарок (создание)»: ДатаПолученияДохода = СЕГОДНЯ, не дата из задания

    fill_field(field="ДатаПолученияДохода", value="<ДАТА ВЫДАЧИ ДД.ММ.ГГГГ>")
    select_value(field="Организация", search="<ОРГАНИЗАЦИЯ>")
    get_form_state()
        # сверить: ДатаПолученияДохода = дата выдачи из задания (выбор организации её не сбрасывает),
        # МесяцНачисленияСтрокой, КодДоходаНДФЛ 2721, КодВычетаНДФЛ 501,
        # ВидПризаПодарка — «Подарок» или «Приз, выигрыш в конкурсе», как в задании

    click(text="Подбор")
    filter_list(text="<ФАМИЛИЯ>")
    click(text="<ФИО полностью, как в списке>", double_click=true)
    click(text="Выбрать")

    fill_table_row(fields_json="{\"Сумма дохода\": \"<СУММА цифрами без пробелов>\"}", row_index=0, table="Начисления")
    click(text="Провести")
    get_table(table="Начисления")     # Сотрудник, Сумма дохода, Код вычета 501, Сумма вычета
    get_form_state()                  # в заголовке номер документа; ДатаПолученияДохода не уехала
    close_form()

## Ловушки

1. **Главная — дата.** Поле `ДатаПолученияДохода` подписано «Дата выдачи»
   и встаёт текущей датой сеанса. Документ с ней проводится молча, а НДФЛ
   уезжает в другой период (в 6-НДФЛ строки 140 и 160 расходятся
   по кварталам). `Дата` документа и `ДатаПолученияДохода` — разные поля,
   менять надо второе.
2. **«Сумма вычета» пустая до проведения.** После ввода суммы в строке
   стоит только код 501; сумма вычета появляется после «Провести».
   Вписывать вычет руками не нужно.
3. **НДФЛ 0 — правильно**, пока годовой вычет 501 (4 000 на человека)
   не израсходован. Израсходован другим подарком — налог появится, и это
   тоже правильно.
4. Коды подставляются сами. `КодДоходаНДФЛ`, `КодВычетаНДФЛ` не трогать.
