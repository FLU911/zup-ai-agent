В OpenCode таймеров внутри сессии нет, поэтому «завести регламент» здесь
значит другое: пройти по списку один раз прямо сейчас.

Прочитай `регламент/задания.json`. Для каждого задания из списка, по порядку,
прочитай целиком `.claude/skills/<скилл>/SKILL.md` и все файлы, на которые он
ссылается, и выполни ОДИН тик строго по нему. Следующее задание начинай,
только когда предыдущее доведено до конца.

Правила проекта — в `CLAUDE.md`, они обязательны: имена элементов формы брать
только из словарей, после каждого ввода проверять значение, feature-файлы
не редактировать.

В конце доложи по одной строке на задание: что сделано или что делать было
нечего. И напомни человеку: чтобы проход повторялся сам, в отдельном терминале
запускается `регламент\следить.ps1 -Инструмент opencode` — он живёт, пока
терминал открыт.
